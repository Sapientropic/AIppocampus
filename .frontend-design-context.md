# Frontend Design Context

AIppocampus public web surfaces should feel calm, human, and source-grounded.
The product is a local-first continuity layer, not a generic AI dashboard or a
marketing funnel.

Use old-style, humanist typography with a classical center of gravity: readable
serif body text, restrained display serif headings, and a quiet humanist sans
for navigation and controls. Avoid generic AI-site defaults such as Inter-first
stacks, glossy gradients, dashboard mosaics, exaggerated claims, and content
that mirrors long repository docs.

The README hero image is the canonical spirit image for the public landing
surface: shadow and light reconnecting through a source-like point of contact.
The Code of Conduct lantern and Contributing crystal-heart images are supporting
community motifs. The frosted flower image is better suited to softer wiki or
reflection surfaces than the primary product homepage.

The favicon/app icon should stay simpler than the artwork: a dark old-world
seal, memory-labyrinth ring, and one warm source point. It needs to read at
browser-tab scale before it reads as an illustration.

Canonical content remains in the repository docs and Wiki. Public web pages
should act as signposts: what AIppocampus is, why it matters, how to inspect it,
and what it cannot claim yet.
