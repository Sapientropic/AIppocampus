# Commercial Extensions

The public AIppocampus repository is licensed under Apache-2.0. This file does
not change the repository license and does not grant commercial service terms.

Commercial, hosted, enterprise, or separately packaged products may be offered
under separate written agreements. Those products can include managed sync,
governance, hosted semantic/graph services, enterprise deployment automation,
support, compliance, retention, backup, and other operated surfaces that are not
shipped as Apache-2.0 code in this public repository.

The canonical boundary between the Apache-2.0 public core, private user data,
and commercial/separate-license product surfaces is
`docs/guides/public-core-boundary.md`.
