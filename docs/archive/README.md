# Archive

This folder holds historical, superseded, or one-off working material that is
still useful for provenance but should not sit on the active documentation path.

Archived notes are not current contracts. Before using one as evidence, follow
its links back to the current owner in `docs/README.md`, the roadmap, the
readiness snapshot, or the implementation itself.

## Current Contents

- `superpowers/plans/` - one-time implementation plans generated during prior
  Superpowers-led work. They are retained as historical task context, not as
  active AIppocampus planning docs.
