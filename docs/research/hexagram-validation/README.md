# Hexagram Validation

This folder holds local validation material for the hexagram / five-tone
intuition-layer experiments. It is research evidence, not a runtime contract.

## Files

- [Prompt v1](prompt_v1.md) - cross-model validation prompt.
- [Results v1](results_v1.md) - model comparison results and design correction.
- [Deep Structure Proposal](deep-structure-proposal.md) - follow-up assessment
  of unused deterministic hexagram structures.
- `hexagram_tables.py` - deterministic helper table used by the experiment.
