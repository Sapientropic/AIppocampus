# Long Garden

This folder is for AIppocampus ideas worth preserving without letting them
stand in the default product doorway.

Use a seed when an idea is promising, beautiful, or strategically important,
but not ready to become an open issue. The normal promotion gate is:

- It can be cut into a fixture, doc, CLI, runtime slice, or verified cleanup in
  roughly 1-2 weeks.
- It names the product layer it belongs to: Core default, power user,
  enterprise/high-risk, or research garden.
- It can say how it helps first recall, reduces manual grep, reduces false
  source claims, or improves source-backed wayfinding without adding ordinary
  user ceremony.
- It preserves source-backed evidence boundaries instead of turning summaries,
  symbols, or model-organized impressions into truth.

Examples that belong here until they have small executable slices:

- Situation glyphs, hexagram arcs, and other compact intuition markers.
- Multidimensional active-path networks and richer cognitive-map topology.
- Richer Episode/Arc sequence reasoning beyond the deterministic builder and
  source-reopen helper documented in
  `docs/architecture/coordination/episode-arc-read-models.md`.
- Dream residue, sleep pruning, and active-imagination experiments.
- Reflection-space and Campus-like map rooms before a concrete opt-in UI slice.
- Governance concepts that are valuable for high-risk deployments but would
  make ordinary recall feel like compliance work.

Seeds are not active roadmap commitments. When a seed graduates, link to the
Discussion, issue, fixture, or evidence page that made it executable; do not
mirror the whole design here.
