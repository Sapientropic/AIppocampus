## Plugin Boundary

The plugin is a local install wrapper for the AIppocampus skill and MCP tools.
Installing the plugin does not automatically enable prompt hooks, lifecycle
hooks, external-model routes, hosted storage, or provider API calls.

Those surfaces remain explicit user/operator actions. If a host, marketplace,
or third-party model provider is used, its own terms and privacy policies may
also apply.
