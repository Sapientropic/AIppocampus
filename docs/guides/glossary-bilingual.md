# Bilingual Glossary / 中英术语表

Role: compact terminology bridge for AIppocampus readers and agents.

Canonical source for product posture remains `AGENTS.md`, `llms.txt`, and the
linked guide pages. This glossary keeps translations aligned; it is not a
second copy of the operating contract.

| English term | 中文建议 | Use |
| --- | --- | --- |
| AIppocampus | AIppocampus | Project name; do not translate as only "memory". |
| hippocampus | 海马体 | Biological metaphor for routing and continuity, not a claim of model-native memory. |
| continuity | 连续性 | The user/agent/project thread can be resumed with care. |
| source-backed continuity | 有源连续性 | Continuity that can reopen local clean source before strong claims. |
| clean source | 干净源 / clean source | Redacted, source-reopenable conversation material; summaries are only navigation. |
| recall | 召回 | Find a likely route from a cue. |
| deepen | 深挖 / reopen source | Open the source route before exact wording or sensitive claims. |
| route | 路由 / 线索路径 | Navigation pointer to source, not evidence by itself. |
| source court | 源庭 / source court | The stricter layer where exact source windows and claim boundaries live. |
| layer | 层 | A product or runtime layer; avoid treating layer names as proof. |
| scaffold | 脚手架 | Temporary or supporting structure, not user-facing value by itself. |
| foundation | 地基 | The source-backed mechanism that supports continuity. |
| foreground | 前台 | Agent/user-facing output. |
| operator detail | 操作者细节 | Diagnostic/audit output kept behind explicit detail flags. |
| MCP | MCP | Tool surface for agent integrations. |
| ambient recall | 环境召回 | Gentle prompt-hook context; should stay compact and non-nagging. |
| action grammar | 行动语法 | Boundary such as `direction_only`, `reopenable_route`, or `source_open`. |
| direction_only | 只作方向 | Attention cue only; no factual claim. |
| reopenable_route | 可重开路由 | A route that should be reopened before use. |
| bounded_evidence | 有界证据 | Evidence usable only within declared scope. |
| source_open | 源已打开 | Exact source window is open, still with redaction/scope boundaries. |
