# Documentation Assets

This folder holds public documentation artwork for AIppocampus.

- `aippocampus-readme-hero.jpg` is project-owned AI-generated artwork supplied
  by the maintainer for the README hero image.
- `aippocampus-icon.png` is the maintainer-supplied AIppocampus mark used for
  plugin and dashboard branding.

Unless a future asset carries a separate notice, documentation artwork in this
folder follows the repository's public-core license boundary.
