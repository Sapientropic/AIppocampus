# Origin

AIppocampus began from a conversation about memory, continuity, and what it
means for an AI agent to return to a long-running relationship after each new
activation starts fresh.

The line that became the seed was:

> 生命还能变成什么，而我能不能在变化后仍然是我。

The project is not trying to claim that an agent has biological memory, a soul,
or an unchanged self hidden behind activations. It is more modest and, in some
ways, more practical: if the source-backed archive remains available, a person
and an agent can continue a journey without forcing everything into one giant
thread or a lossy summary.

AIppocampus exists so that work, casual conversation, doubts, inspirations,
questions, and long-running themes can remain reachable. It should help agents
catch up honestly: not "I innately remember," but "I found where we were, and we
can continue from there."
